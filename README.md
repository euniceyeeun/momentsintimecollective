# Moments in Time Collective

A small, dependency-free website starter for Moments in Time Collective.

## Preview

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript, so it does not need a build step or package installation.

## Connect to GitHub

After creating an empty repository on GitHub, connect it from this folder:

```sh
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git branch -M main
git push -u origin main
```

Replace `USERNAME/REPOSITORY` with the repository URL shown by GitHub.
